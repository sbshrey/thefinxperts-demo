# TheFinxperts public demo

Fictional portfolio example, browser-only manual/simple CSV and mapped broker XLSX/CSV inputs, CAMS Active Statement PDF or HTML preview, multiple goals with optional whole-percentage sharing of holdings across goals, optional dated fund TER entry and cost coverage, optional separate reserve arithmetic, comparison against an investor-entered asset mix, and private readable-summary/JSON downloads. Investors can mark mutual funds and direct stocks as all included, partly included, absent, or unsure; this self reported answer clears when holdings change. Each holding shows its original entry route and valuation date; this is provenance, not independent verification. The Active Statement preview shows reconciled individual schemes and their source categories when possible, combining repeated matching scheme rows; otherwise it shows fund-house totals; a later complete statement can update matched funds, add new fund rows and remove absent ones with a reviewable change list and confirmation while keeping direct stocks. It never claims constituent overlap. Broker report rows require investor classification. No account server, original CAS PDF importer, live data, or investment advice is included in this static site.
