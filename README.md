# TheFinxperts public demo

Fictional portfolio example, browser-only manual/simple CSV and mapped broker XLSX/CSV inputs, CAMS Active Statement PDF or HTML preview, multiple goals with optional whole-percentage sharing of holdings across goals, optional dated fund TER entry and cost coverage, optional separate reserve arithmetic, comparison against an investor-entered asset mix, and private readable-summary/JSON downloads. The Active Statement preview shows reconciled individual schemes and their source categories when possible, otherwise fund-house totals; a later fully matching statement can refresh those funds while keeping stocks and goal links. It never claims constituent overlap. Broker report rows require investor classification. No account server, original CAS PDF importer, live data, or investment advice is included in this static site.
