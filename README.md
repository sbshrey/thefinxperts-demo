# TheFinxperts public browser review

Fictional portfolio example, browser-only manual/simple CSV and mapped broker XLSX/CSV inputs, CAMS Active Statement PDF or HTML preview, multiple goals with optional whole-percentage sharing of holdings across goals, optional dated fund TER entry and cost coverage, optional investor-checked invested amount and partial unrealized gain or loss for individual holdings with dated values, optional separate reserve arithmetic, comparison against an investor-entered asset mix, and private readable-summary/JSON downloads. The guided chat can stage up to 30 explicit holdings pasted one per line, with confirmation before totals change. Unknown individual fund asset categories in the draft list can be labelled in numbered batches after the investor checks each scheme source; confirmed categories can be corrected in chat after an explicit preview, without changing values or goal links. A single-goal investor can confirm in chat that all unassigned holdings count toward that goal, and a broad improvement question names a sourced factual review check. Optional separate reserve totals can be confirmed in chat and compared with essential spending without an adequacy score. The guided review can optionally save an encrypted copy of confirmed holdings and goals on this device with a user-chosen passphrase; refresh requires unlocking again, and the separate file backup remains available. Ask this review answers bounded factual questions from current in-tab calculations without AI or a credit. A restorable JSON backup can include unfinished goals; the readable analysis summary waits only for confirmed details for the selected goal. Investors can mark mutual funds and direct stocks as all included, partly included, absent, or unsure; this self reported answer clears when holdings change. Exact matching manually entered ISINs or names prompt the investor to check whether a second position is genuinely separate. Each holding shows its original entry route and valuation date; this is provenance, not independent verification. The Active Statement preview shows reconciled individual schemes and their source categories when possible, combining repeated matching scheme rows; otherwise it shows fund-house totals; a later complete statement can update matched funds, add new fund rows and remove absent ones with a reviewable change list and confirmation while keeping direct stocks. A newer original mutual-fund CAS or broker report can refresh exact unique ISIN matches after a reviewable preview while leaving unmatched rows out; a CAS refresh also replaces units and keeps investor-checked asset labels. It never claims constituent overlap. Guided broker imports use explicitly labelled type, asset-class and ISO valuation-date columns when present; otherwise the investor supplies missing facts. Unsupported or conflicting labels stop the import. The guided review also tries original CAMS/KFintech mutual-fund CAS PDFs entirely in a browser worker, shows normalized drafts and requires confirmation; unsupported layouts stop without importing. No account server, demat CAS importer, live data, or investment advice is included in this static site.
