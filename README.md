# TheFinxperts public browser review

Fictional portfolio example, browser-only manual/simple CSV and mapped broker XLSX/CSV inputs, CAMS Active Statement PDF or HTML preview, multiple goals with optional whole-percentage sharing of holdings across goals, optional dated fund TER entry and cost coverage, optional investor-checked invested amount and partial unrealized gain or loss for individual holdings with dated values, optional separate reserve arithmetic, comparison against an investor-entered asset mix, and private readable-summary/JSON downloads. The guided review can optionally save an encrypted copy of confirmed holdings and goals on this device with a user-chosen passphrase; refresh requires unlocking again, and the separate file backup remains available. Ask this review answers bounded factual questions from current in-tab calculations without AI or a credit. A restorable JSON backup can include unfinished goals; the readable analysis summary waits only for confirmed details for the selected goal. Investors can mark mutual funds and direct stocks as all included, partly included, absent, or unsure; this self reported answer clears when holdings change. Exact matching manually entered ISINs or names prompt the investor to check whether a second position is genuinely separate. Each holding shows its original entry route and valuation date; this is provenance, not independent verification. The Active Statement preview shows reconciled individual schemes and their source categories when possible, combining repeated matching scheme rows; otherwise it shows fund-house totals; a later complete statement can update matched funds, add new fund rows and remove absent ones with a reviewable change list and confirmation while keeping direct stocks. A newer broker report can refresh exact unique ISIN matches after a reviewable preview while leaving unmatched rows out. It never claims constituent overlap. Guided broker imports use explicitly labelled type, asset-class and ISO valuation-date columns when present; otherwise the investor supplies missing facts. Unsupported or conflicting labels stop the import. No account server, original CAS PDF importer, live data, or investment advice is included in this static site.
