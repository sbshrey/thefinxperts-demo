# TheFinxperts public demo

Fictional portfolio example, browser-only manual/simple CSV and mapped broker XLSX/CSV inputs, CAMS Active Statement PDF or HTML preview, multiple goals with optional whole-percentage sharing of holdings across goals, optional dated fund TER entry and cost coverage, comparison against an investor-entered asset mix, and private readable-summary/JSON downloads. The Active Statement preview shows AMC-level totals only. Broker report rows require investor classification. No account server, scheme-level CAS PDF importer, live data, or investment advice is included in this static site.
